# DevOps Chatbot Application

![App Screenshot](/screenshots/demo1.png)

A Python-based chatbot with DevOps knowledge, built with Tkinter and Gemini AI API.

## Features
- Natural language processing for DevOps queries
- Time/date awareness
- Contextual responses
- Clean GUI interface
- Gemini AI integration

## Technologies
- Python 3
- Tkinter (GUI)
- Google Gemini AI API
- datetime
